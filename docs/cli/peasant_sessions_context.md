## peasant sessions context

Show entries around a target entry in a session transcript

### Synopsis

Show a window of session transcript entries centered on --turn N.

--turn N uses entry_index directly (raw DB index, not a dense ordinal).
-C K shows K entries before and K entries after the target, clamped to
the session boundaries.

Each entry (depth=0 and depth=1) is displayed on its own line. Depth=1
entries are visually indented. Tool entries use box-drawing characters.

If --session is omitted, recent sessions are listed so you can pick one.

```
peasant sessions context [flags]
```

### Options

```
  -C, --context int                Number of entries to show before and after the target (default 3)
      --format-tool-calls string   How to render tool calls: verbose (full box), compact (one-line), or quiet (hidden) (default "verbose")
  -h, --help                       help for context
      --json                       Output as JSON
      --session string             Session ID to inspect
      --turn int                   Target entry_index (center of the context window); 0 = first indexed entry
```
