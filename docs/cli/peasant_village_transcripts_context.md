## peasant village transcripts context

Render a pulled transcript in the terminal (offline)

### Synopsis

Render a previously pulled village transcript in the terminal.

The reference is the transcript UUID or a pasted village web URL — the same form
'village transcripts pull' accepts. The transcript must already be pulled
locally; this command reads only local data and works offline.

By default the WHOLE transcript is rendered. Pass --turn N to highlight (and,
with -C K, window around) a specific entry. Tool calls are rendered with the
same --format-tool-calls options as 'peasant sessions context'.

```
peasant village transcripts context <uuid|url> [flags]
```

### Options

```
  -C, --context int                With --turn, number of entries to show before and after the target (default 3)
      --format-tool-calls string   How to render tool calls: verbose (full box), compact (one-line), or quiet (hidden) (default "verbose")
  -h, --help                       help for context
      --json                       Output the projected entries as JSON
      --turn int                   Highlight the entry at this index (default: render the whole transcript with no center marker) (default -1)
```
