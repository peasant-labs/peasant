## peasant annotate import

Import annotations from JSONL files

### Synopsis

Import annotations from JSONL files produced by 'peasant export annotations'.

Each line in the JSONL file must be a valid ExportedAnnotation record.
Invalid records are skipped with a warning; valid records are imported.

```
peasant annotate import [flags]
```
