## peasant reclaim

Reclaim superseded managed generations (rows and blob directories)

### Synopsis

Remove the managed generations a session no longer reads.

Only a session's active generation is read; every superseded generation keeps its
projection rows and its content-blob directory. This command deletes those rows in
one transaction and removes the superseded generation directories through the
ownership-verified cleanup path. A session with a pending activation intent is left
alone, the active generation is never touched, and a missing directory is success,
so an interrupted run is safe to repeat.

Run with --dry-run first: it lists the sessions, generations, rows and bytes it
would reclaim and changes nothing.

SQLite reuses the freed pages but does not shrink the database file. To reclaim the
disk space, stop every process using the database and run the offline VACUUM:

  peasant reclaim --dry-run          # confirm nothing is left
  sqlite3 <db> 'VACUUM;'             # offline; needs exclusive access

The database path is printed after a successful run.

```
peasant reclaim [flags]
```
