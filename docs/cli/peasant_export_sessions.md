## peasant export sessions

Export session transcripts as JSON

### Synopsis

Export session transcripts as JSON files with full turn content.

Each session uses a coherent snapshot of stored input and indexed coordinates,
producing a JSON envelope with full content. Stale or unproven inputs are refused.

A session that keeps a newer incomplete attempt beside its last-good generation
is refused by default: the newer attempt is never exported as the session, and
the last-good content is not leaked past the refusal. Pass --last-good to export
the last-good full authority explicitly.

Requires either --session for a single session or --session-from-file for a batch.

```
peasant export sessions [flags]
```

### Options

```
  -h, --help                       help for sessions
      --last-good                  Export the last-good full transcript when a newer incomplete attempt is kept beside it. Without it such a session is refused rather than exporting the incomplete attempt; the store resolves the last-good authority server-side, so no session or generation identifier is accepted
      --output-dir string          Directory to write exported session JSON files (default ".")
      --session string             Single session ID to export
      --session-from-file string   Path to a newline-delimited file of session IDs to export
```
