# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's **Report a
vulnerability** form in the repository's Security tab to submit a private report.

Include the affected version, impact, reproduction steps, and any suggested mitigation. Remove real
credentials, private transcripts, and unrelated personal data; use minimal synthetic examples.

Maintainers will acknowledge the report through GitHub's private vulnerability reporting channel,
investigate it, and coordinate disclosure there. We do not promise a fixed response or remediation
timeline.

For ordinary bugs without a security impact, use the public bug-report template.
