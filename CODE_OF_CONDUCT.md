# Code of Conduct

## Our standard

We are committed to a welcoming, harassment-free project. Be respectful, assume good intent, give
actionable feedback, and focus discussion on the work and its effect on users.

Unacceptable behavior includes harassment, discrimination, threats, sexualized attention, personal
attacks, deliberate intimidation, publishing another person's private information, and sustained
disruption of project spaces.

## Scope

This code applies in repository discussions, issues, pull requests, reviews, and other spaces where
someone represents the project.

## Enforcement

Report conduct concerns privately to the repository maintainers through GitHub. Do not use a public
issue when doing so would expose a target or sensitive information. Maintainers may remove content,
limit participation, or ban participants when behavior is harmful or persistently disruptive.

Maintainers will handle reports as confidentially as practical and will avoid conflicts of interest
when reviewing them. Enforcement decisions should consider context, impact, and patterns of behavior.
